# RingX Radar for ROB RUN (free build)

Download: soon

Radar-only cut of the RingX build.

## Widget

| Setting | Default | Range |
| --- | --- | --- |
| scale | 90% | 55-140 |
| opacity | 70% | 20-100 |
| range | 450 m | 150-800 |
| rings | on | on/off |
| vehicle dots | on | on/off |

Drag to place, F9 hides it, position persists.

## Install

Admin loader, start game, INSERT, F9 to show.

## Troubleshooting

Widget resets: leave via menu. Dots freeze: restart loader.

Windows 10/11, Steam, EAC.
